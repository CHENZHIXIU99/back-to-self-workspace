# BackToSelf Workspace

一个移动端优先、可安装、离线可用的个人综合工作台。数据默认通过 IndexedDB 保存在当前设备；计时状态使用 localStorage 恢复。

## 在线使用

访问：<https://chenzhixiu99.github.io/back-to-self-workspace/>

每台设备首次打开都是全新的空白工作台。不同用户之间不会共享任务、账单、照片、健康或周期数据。

## 已实现

- 今日工作中枢、今日状态与低精力提示
- 每日任务、月历日程、临时任务及任务转换
- 可跨刷新恢复的专注计时器
- 健康、睡眠、体重、每日饮品卡通贴纸、每日穿搭与姨妈周期统一记录
- 收支记录、分类统计与预算进度
- 播客/读书/灵感笔记及行动转任务
- 5·3·2·1 情绪落地练习与消息边界
- 每周复盘、Markdown 周报导出
- 全局搜索、深色模式、JSON 备份与恢复
- PWA 桌面安装、离线缓存、320px 移动端适配

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开终端显示的本地地址。

## 检查

```bash
npm run lint
npm run test
npm run build
```

## 手机安装

- iPhone：使用 Safari 打开站点，点击“分享”→“添加到主屏幕”。
- Android：使用 Chrome 打开站点，点击菜单→“安装应用”或“添加到主屏幕”。

## 数据说明

当前数据仅保存在本设备浏览器中。首次打开为空白状态，不预置演示数据。饮品和穿搭照片同样只保存在当前设备。清除浏览器数据可能导致记录丢失，请在“设置与数据”中定期导出 JSON 备份。
